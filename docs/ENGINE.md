# Движок и формат контента

Короткая шпаргалка для следующих сессий. Типы — `shared/src/content.ts`, исполнение —
`server/src/engine/index.ts`, отображение — `server/src/engine/view.ts`.

## Команды

```
npm run dev:server     # сервер с автоперезапуском (порт из PORT, по умолчанию 8080)
npm run dev:client     # Vite с прокси /ws -> :8080
npm run build          # client/dist + dist/index.js, dist/backup.js
npm test               # все тесты (vitest)
npm run validate       # валидатор контента
npm run typecheck
```

Дев-мир для ручной проверки: `DATA_DIR=... npx tsx scripts/seed-dev-world.ts done:s_09`
(боты доигрывают до флага и сохраняют мир). Дым-тест живого сервера: `scripts/smoke-ws.ts`.
Бои Монте-Карло по этапам снаряжения: `npm run sim [прогонов] [фильтр]` (`scripts/sim.ts`).

## Вторая часть: каркас (кратко)

Формулы — `shared/src/rules.ts`; герой и торба — `engine/hero.ts`; бой — `engine/fight.ts`;
карта, засады, жители — `engine/travel.ts`; наследие первой части — `server/src/legacy.ts`.

- **Места = AreaDef** с `pos`, `links[{to,time}]`, `danger`, `foes[]` (таблица встреч), `ambush`
  (шанс нападения на действие/приход), `cond[]` (без защиты/инструмента — урон за действие), `home`,
  `scout` (сцена-разведка: пока не пройдена вдвоём, место не открыто для одиночки; предлагается
  из соседнего места). Переход — команда `go` (занятость, тяжёлая торба замедляет).
- **Герой**: `level/xp/points/stats/perks/perkChoice/skills/equip/sets/bag`. Очко за уровень
  (команда `stat`), перк на уровнях `hero.perkLevels` (команда `perk`). Навыки растут от `skill`
  действий и `train`. Отдых лечит (дома быстрее).
- **Вещи**: ресурс `kind: 'gear'` + `gear` (слот, броня, урон, теги, сопротивления, инструменты,
  `ammo`). Надевается только дома из общего склада (`equip`), комплекты (`outfit`).
  `kind: 'use'` + `use` — расходники (лечение, снять яд/пиявку, напугать, бросить), лежат
  в торбе; `pack` — взять с собой. Торба: вес `weight`, вместимость от Силы и вещей; дома
  всё (кроме `use`) выгружается на склад.
- **Действия**: `tool` (нужен инструмент, иначе кнопка с причиной), `boost` (ускоряет),
  `skill`, `knack {role,x}`, `limit` (рецепт исчезает, когда вещей достаточно), `why` (зачем),
  `job {rate}` (можно поставить жителя: единиц в час), `train`. Вдали от дома добыча — в торбу.
- **Бой (`fight.ts`)**: раунды; враги показывают намерение (`ai[]`: attack/charge/grab/drag/
  leech/venom/steal/call/guard, `every/from/once`), Ловець видит следующее намерение звіра,
  Майстер бьёт по броне вполовину. Особенности (`traits`, `hidden` — раскрывает Ловець или опыт).
  Хватка — только «вырываться», освобождает напарник; пиявка только пьёт. Поднять упавшего — раз за бой.
  Страх (`morale`) — зверь бежит. Люди (`humane`) только падают. Фазы босса (`phases`).
  Поражение в рутине: дом, торба пропала, 60 с отлежаться; в сцене (узел `fight`): узел `lose`.
- **Жители**: `ResidentDef` (черты: `mult`, `avoid`), эффект `resident`, команда `job`.
  Работают в реальном времени (и офлайн), едят `content.food` раз в час, упираются в склад.
- **Наследие**: мир первой части (в `world.db` или `DATA_DIR/part1.db`) читается один раз:
  герои, `bg_*`, концовка → флаги `legacy_*` (см. `legacyFlags`).
- **Погода (`engine/weather.ts`, `content/weather.ts`)**: одна на двоих, `WorldState.weather
  {id, until, next}`; начинается с `weather.from`, держится `span` (случайно), потом приходит
  прогноз `next`; ужин (`advanceDay`) тоже меняет погоду. Пока никого нет в сети или идёт общая
  сцена — ждёт. `WeatherDef`: `pace`/`travel`/`ambush`/`jobs`/`xp` (множители), `chill` (холод
  в минуту, минус — греет), `dry` (сушка, 0 — не сохнет без огня), `frozen` (мокрые места не мочат),
  `bonus {fx, p}` (работа с таким акцентом иногда даёт +1; кроме побочек и разовых), `sky` (вид).
  Действует только «надворі»: не дома и не в месте с `roof`; жители и засады — по месту.
  Клиент: значок в шапке с карточкой эффектов и прогнозом (`client/src/weather.tsx`), слой неба
  в `ambient.tsx`, звук дождя/грозы/ветра в `sound.ts`. Условие `{weather: id}`.
- **События (`engine/events.ts`, `content/events.ts`)**: `EventDef {where: home|road|place, areas,
  when, weight, once/again, text, effects | choices[{label, cost, if/why, outcomes[{w, effects, log}]}]}`.
  Таймер на каждого героя и на дом (`events.gap`); домашнее приходит, когда кто-то дома, дорожное —
  при приходе (шанс `road`), место — после работы (шанс `place`), если не было засады. Без выбора —
  строка журнала и эффекты сразу; с выбором — карточка (`WorldState.events.open`), команда `event`.
  Домашнюю карточку видят и решают оба, кто дома; чужую — только тот герой, пока он на месте.
  Не в бою и не в общей сцене. Условие `{resident: id}`. `heal` с минусом не роняет ниже 1.
- Новые эффекты: `xp`, `resident`, `checkpoint` (снимок мира в архив БД), `give` (в торбу),
  `wear` (надеть), `fight` (начать бой). Новые условия: `level`, `tool`, `owns`, `trait`, `met`,
  `evening`. Движок сам ставит флаг `bag_full`.

## Сущности контента

- **AreaDef** — область (место, где находится игрок): `id`, `name`, `where` («у Ясенці»).
  У игрока `at`; карточки мест (`LocationDef.area`) видны только в своей области; совместная
  сцена требует обоих игроков в области её группы. Переход — эффект `moveTo`.

- **ResourceDef** — ресурс/предмет. `cap` + `capBonus`, `hidden` для внутренних запасов,
  `kind: 'tool'` — показывается в «Речі».
- **LocationDef** — карточка места (группа кнопок). `visible` — когда появляется.
- **ActionDef** — рутинная кнопка (только соло). `role`, `once`/`oncePerPlayer`, `visible`,
  `enabled`+`disabledHint`, `cost`, `yield` (число или `[min,max]`), `chance[]`, `rollsPer`
  (повторить броски по числу ресурса), `effects`, `cooldown` (занятость, мс), `recharge`,
  `busy` (статус для партнёра), `log` (self/other/all; массив строк = случайный выбор),
  `beats[]` (одноразовые виньетки), `gives` (текст «что даёт», если движок не может вывести
  это сам: улучшения, открытия). Подпись «что даёт» строится автоматически: точные числа,
  диапазоны, `+?` для удачи и неизвестного.
- **PoolActionDef** — совместная кнопка, запускающая сцену из пула (`supper`).
- **SceneDef** — совместная сцена. `group`+`label` — кнопка предложения. `explores` — помечает
  место исследованным. `cost` списывается при старте. `once` (по умолчанию true).
  Узлы: текст (`next`, `goto`, `button`, `incomplete`), выбор (`mode: joint|each|any`,
  `mismatch`), бой (`enc`, `win`, `lose`). У любого узла: `text` (общий), `hunter`/`maker`
  (личный, получает только эта роль), `effects`.
- **EncounterDef** — бой: враг (`hp`, `fear`, `dmg`), опции (урон, страх, защита, стоимость),
  `downOption` для упавшего, `ally`, `armor`, `maxRounds`.
- **Узел `delve`** (спуск): `map` (id из `content.maps`), `light` (+`bonus[]`), `starts[]` (старт в другой
  комнате по условию), `out` (выход из стартовой комнаты), `dark` (свет кончился). Партия ходит,
  когда оба выбрали один путь (`go:<room>`); действия комнаты (`act:<id>`) — сразу, одним игроком;
  `leave` — только в стартовой комнате. Флаги: `known:<map>:<room>`, `found:<map>:<room>` (первые
  находки `first`), `dact:<map>:<act>` (одноразовые действия). Комната может уйти в узел сцены
  (`enter: [{if, next}]`) — когда сцена вернётся в узел карты, спуск продолжится с того же места.
- **DelveMapDef**: `rooms` с `pos` (сетка для рисунка), `text`/`hunter`/`maker`, `exits[]` (`light`,
  `hunter`/`maker` — что замечает роль, `draft` — Ловець чует протяг, `risk` — плохой камень, Майстер
  видит его заранее), `acts[]` (`light` отрицательный = добавляет свет, `cost`, `effects`, `once`).
- **Узел `stealth`** (мимо сторожей): `path` (true = сипкий камень, видит Майстер), `watch` (ритм
  взглядов, видит Ловець), `alarm`, `time`, `bonus[]`, `sees` (тексты), `win`/`lose`. Каждый ход оба
  выбирают `step` / `sneak` (тихо, но время ×2) / `freeze`. Взгляд + движение — тревога +2, обычный
  шаг по сипкому — +1. Валидатор проверяет, что идеальная игра укладывается во время.
- **Узел `operation`** (два фронта): `turns`, `tracks[]` (`max`, `flag` — значение живёт во флаге мира
  и пишется каждый ход, `bad` — дошла до `max` → `fail`), `moves[]` (`role`, `visible`, `enabled`,
  `cost`, `delta`, `transfer {from,to,n}` — перелить до `n` из одной шкалы в другую, `bonus[] {if, delta?, n?}`,
  `log`), `events[]` (`from`, `every`, `if`, `delta`, `text`). Каждый ход оба выбирают ход; в конце —
  `win {track, gte, next}`, иначе `lose`. Валидатор требует у каждой роли всегда доступный ход.
- **Знаки руками**: команда `sign` (`stop|go|quiet|danger|here`) в любой сцене; в виде — свой и
  свежий знак напарника (в `stealth` — показанный в этот ход).
- **LocationDef.progress** `{flag, max, label}` — общая работа с полосой прогресса в карточке места.
- **EncounterDef.bars** — подписи двух шкал боя, если они означают другое (сторожа / Книга горит).
- **ClueDef** (`to: both|hunter|maker`, `mystery`), **MysteryDef**, **GoalDef** (`when`,
  первая подходящая в списке — текущая цель), **NpcDef**.

## Автоматические флаги

`done:<scene>`, `count:<scene>`, `seen:<loc>` (сцена с `explores`), `built:<action>` (once),
`beat:<action>:<i>`, `<enc>:killed` / `<enc>:fled`. Личные флаги игроков — `pset`/`pflag`.

## Условия и эффекты

Условия: `flag` (с `gte`/`lt`), `noFlag`, `pflag`, `noPflag`, `partnerPflag`, `res`, `day`,
`role`, `clue` (у смотрящего), `anyClue`, `partnerJoined`, `partnerOnline`, `stove`, `rel`,
`weather`, `resident`, `all`/`any`/`not`.

Эффекты: `set`, `unset`, `inc` (`by`, `max`), `pset` (`who: actor|both|hunter|maker`), `add`, `take`, `clue`,
`log`, `mystery` (поднять уровень), `rel`, `meet`, `scene` (только из сцен — цепочка),
`advanceDay`, `heal`, `stove`, `actDone`, `startAct`, `moveTo` (`who`), `if/then/else`.
Условия мест: `at`, `partnerAt`.

## Тексты

- `Text` = строка или массив вариантов `{ if, text }` (первый подходящий).
- `Paras`: строка — абзац; массив только из вариантов — один абзац; иначе список абзацев,
  где объект — условный абзац, вложенный массив — группа вариантов.
- Шаблоны: `{name}`, `{partner}`, `{a|b}` (род субъекта), `{p:a|b}` (род партнёра),
  `{role}`, `{p:role}`. Имена — только в именительном падеже.
- В логах `self` — от второго лица для действующего, `other` — для партнёра
  (`{name}` = действующий), `all` — всем.

## Правила

- ID нейтральные (`s_12`, `c_07`, `x_33`, `e_05`), читаемые алиасы — в `content/a1/ids.ts`.
- Сцены нельзя запускать из соло-действий (валидатор ругается).
- Каждая цена ≤ максимальной вместимости, у каждого ресурса — бесконечный источник.
- Любой новый акт: валидатор без ошибок, тест языка, автопрохождение до конца акта.
