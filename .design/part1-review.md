# Аудит первой части («Безгомін»)

> Секретный документ дизайнера. Игрокам не цитировать. Сюжетная правда первой части —
> в `content/secret/` (STORY, ACTS, REVEALS, ENDINGS, STATUS); здесь — выводы для второй.

## 1. Стек и архитектура

| Слой | Что есть | Оценка |
|---|---|---|
| Язык | TypeScript везде, один `package.json` | оставить |
| Сервер | Node 24, `ws`, авторитетный; `World` в памяти, команды → движок → `PlayerView` на игрока | оставить |
| Хранение | `node:sqlite`: одна строка JSON мира, архив перед миграцией, бэкап при старте, STATE_VERSION 3 + цепочка миграций | оставить, расширить (снимки чекпоинтов) |
| Вход | код приглашения + 2 слота, токен в localStorage, лимит попыток | оставить |
| Клиент | Preact + Vite, тонкий: получает готовый вид, шлёт команды; Літопис-дизайн, нижние вкладки на телефоне | оставить оболочку, переделать экран рутины под новый каркас |
| Атмосфера | `ambient.tsx` (canvas погода/огонь/эффекты), `sound.ts` (синтез Web Audio, 30 видов звуков), уведомления, сумерки | оставить целиком — игрокам очень понравилось |
| Кооп-сервисы | «поки тебе не було», итог акта, «напарник може тут», всплывашки склада, знаки руками | оставить |
| Движок | `server/src/engine/index.ts` 1370 строк: действия-кнопки с cooldown, сцены-графы (text/choice/combat/delve/stealth/operation), условия/эффекты, улики, цели, ужины-пулы | сценный движок оставить для сюжета; **рутину переписать** |
| Контент | `content/act1..5` TS-модули: 89 действий, 74 сцены, 5 боёв, 40 ресурсов, 23 места, 85 улик | как данные — хорошо; для второй части — новый набор |
| Тесты | vitest: автопрохождение двумя ботами до финала, валидатор графа и «возобновляемости», робастность (обнуление склада), WS, миграции, язык | оставить подход; боты нужны новые под новый каркас |
| Деплой | Docker + Caddy, `DEPLOY.md` | оставить; вторая часть — отдельный стек/порт/каталог на VPS, первую не трогать |

**Что мешает расширению под обязательный каркас.** В первой части нет RPG-модели вообще:
нет характеристик, уровней, навыков, слотов снаряжения, врагов с уровнями и особенностями,
карты-графа с переходами, лута, бестиария, смерти и чекпоинтов, жителей с чертами и
назначением (есть лишь «Вільні руки» → +2 ресурса в день). Рутина — «кнопка в месте →
занятость N секунд → ресурс». Бой — 5 сценарных столкновений с 4 опциями.
→ Решение: **инфраструктуру, сценный движок и клиентскую оболочку переиспользуем**,
игровую модель рутины (персонаж, вещи, карта, бой, дом, жители) пишем заново как общий
модуль правил в `shared/` (чистые функции, работают в node-симуляторе). Состояние второй
части — новый мир (отдельная БД), наследие первой — импортом.

## 2. Карта механик

| Механика | Акт | Решения или клики | Развитие |
|---|---|---|---|
| Сбор ресурсов кнопками с занятостью | 1 | в основном клики | только новые кнопки в новых местах |
| Скрытые конечные запасы (погреб, лом, мука) | 1 | слабые | нет |
| Піч: топливо, холод ×1.5 к времени | 1 | маленькое решение (подкинуть дров) | нет, только в Ясенці |
| Крафт на верстаке (стрелы, силки, факелы, лук) | 1 | слабые: одна линейка | новые рецепты актов, без ярусов |
| Постройки-улучшения (once) | 1–2 | слабые | нет |
| Совместные сцены и ужины (смена дня) | 1–5 | да: голосования joint/each | ядро игры |
| Разделённая информация (ролевые улики, Панас: жесты/дощечка) | 1–5 | **да, лучшее** | развивалось (знаки, delve, stealth) |
| Бой (раунды, оба выбирают, HP/страх) | 1–5 | средние | почти не менялся, 5 боёв за игру |
| Две базы и переходы | 2 | слабые | 3 области к акту 3 |
| Доверие NPC (rel) | 2 | да (как говорить) | точечно |
| Тревога/скрытность в вылазках | 3 | да | затем stealth в акте 4 |
| Спасение и громада (люди как ресурс, «послать по дрова») | 3 | слабые: одна кнопка | **зачаток жителей** — развить |
| Спуск с картой и светом (`delve`) | 4 | **да** | новый |
| Проход мимо стражи (`stealth`), знаки руками | 4 | **да, кооп по описанию** | новый |
| Общая работа с полосой (конвейер ролей) | 4–5 | средние | новый |
| Два фронта (`operation`) | 5 | да | финал |

Вывод: механики с настоящими решениями появились поздно (акты 4–5). Акты 1–3 держались
на сюжете и разговорах; рутина — однообразная.

## 3. Игровой цикл по актам

- Акт 1 — сбор/крафт в селе + обход мест сценами. Цикл свежий первые ~40 мин, дальше ровный.
- Акт 2 — то же у второй базы + переходы, торговля. **Цикл почти не изменился** (~2 ч).
- Акт 3 — вылазки-сцены за затычки и факелы, спасение. Рутина та же (~2,5 ч).
- Акт 4 — спуск, стража, знаки, общая работа: цикл заметно поменялся.
- Акт 5 — подготовка + операция «два фронта» + финал.
Участок «одного и того же» — акты 1–3, около 5–6 часов. Это совпадает с прямой жалобой
игроков (ниже).

## 4. Кооператив

- **Реально нужны друг другу:** разговоры с глухим (половина у каждого), ролевые улики
  (следы/тексты), спуск (протяг видит один, плохой камень — другой), стража (ритм видит один,
  сыпучие плиты — другой) и знаки руками, конвейер «расшатать/вынести», операция финала.
- **Параллельно:** вся рутина: каждый жмёт свои кнопки, общий склад. Сюжет вместе, но
  большая часть времени в сценах — чтение и голосование.
- Совместных решений (joint) — 27, личных (each) — 12. Совместных «головоломок на двоих» —
  по сути 3 (delve ×2, stealth), все в акте 4.
- Удачно: «напарник може тут», видно, что он делает, его эффекты рядом, «поки тебе не було».

## 5. Телеметрия

В мире с акта 3+ есть `stats` (действия по игрокам, собрано, скрафчено, переходы, ужины),
но сервер игроков не трогаем. Локальная `data/world.db` — тестовая, не их. Если игроки
пришлют бэкап своего мира после финала — разобрать: распределение действий, дни по актам.
Боты (автопрохождение): занятость 5–9 мин на игрока за акт; основное время у людей — чтение
и обсуждение.

4. **Боёв мало, и они очень простые.**
5. Вечер — **меньше часа**.
6. Хочется всего больше; можно дробить акты на подшаги (акт 1.1, 1.2…), чтобы каждый акт был

7. Устройства — по-разному (и телефон, и ПК).
8. Язык второй части — **украинский**.

### Следствия для дизайна
- Каждый рецепт виден, только когда у него есть причина (нужда локации, врага, сюжета);
  бесполезный крафт не показывать вообще. Рецепт = ответ на проблему.
- Прогресс сюжета упирается в готовность: локация/враг требует снаряжения и навыков,
  а не просто нажатия «далі». Рутина — подготовка к конкретной цели, а не фон.
- Бои — системные, частые, с тактикой и особенностями врагов; боссы на двоих, с поражением
  и откатом к чекпоинту. Сложность заметно выше первой части.
- Вечер < 1 ч: одна вылазка/цель на вечер, понятная точка остановки, чекпоинты, быстрый
  вход («поки тебе не було»). 40+ ч = много вечеров — темп открытий не реже раза за вечер.
- Акцент: головоломки (особенно на двоих, с разделённой информацией) и исследование (карта,
  туман, скрытые места).
- Акты делятся на подшаги; поставка по подшагам.
