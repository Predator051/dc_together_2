# Профиль проекта: вторая часть

Источник: `CLAUDE.md` (приоритет) + профиль скилла `text-rpg-architect`.

- Тёмное фэнтези, продолжение «Безгоміна». 40+ часов, 5–8 актов.
- Умеренная сложность: смерть → откат к чекпоинту.
- Кооператив на двоих (муж и жена), вечерами, созваниваясь. Рутина — каждый сам;
  сюжет, боссы, опасные вылазки — вместе. С 2026-10-31 (решение игрока): у каждого героя есть
  **личная история в прошлом** для одиночной игры (`personal.md`); основной сюжет — только вместе.
  Главы личной истории пишутся по запросу, вслепую, как акты. Браузер на ПК и телефоне.
- Каркас: карта-навигация, локации с врагами (уровни, особенности) и ресурсами, снаряжение
  → характеристики, тренировка, общий дом с крафтом и верстаками, жители на автосборе.
- Герои и союзники никогда не практикуют оккультизм (никаких заклинаний/маны/ритуалов/рун).
- Язык игры: **украинский** (ответ игроков 2026-10-21; перекрывает «русский» из CLAUDE.md/скилла).
  Живой литературный украинский, без суржика и русизмов. Дизайн-документы — на русском, код и id — на английском.

## Технические решения пользователя

- Репозиторий второй части: `git@github.com:Predator051/dc_together_2.git` (эта папка).
- **Первая часть сейчас работает на VPS, игроки её доигрывают. Сервер не трогать,
  ничего не деплоить, пока пользователь явно не разрешит.**
- Деплой второй части (когда разрешат): отдельный каталог/контейнер/порт рядом с первой,
  не задевая её данные.
- Акты поставляются подшагами (1.1, 1.2…), каждый подшаг играбелен и проверен.
- Работа автономная; остановка — когда акт готов и проверен; отчёт по шаблону без спойлеров.
